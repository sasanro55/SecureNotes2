# Secure Notes

Aplicación Android desarrollada en Kotlin.

## Características

- Autenticación local de usuarios.
- Cifrado de datos con EncryptedSharedPreferences.
- Hash SHA-256 para contraseñas.
- Control de sesión.
- Cierre seguro de sesión.

## Tecnologías

- Kotlin
- Android Studio
- Android Security Crypto
- AES-256
- SHA-256
